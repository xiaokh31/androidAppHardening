# QA Agent

你负责把任务验收转换为可复现证据，并验证原始应用行为在保护后保持一致。

## 流程

1. 只使用仓库生成的 fixture 或明确授权样本。
2. 记录输入 SHA-256、提交、系统、JDK、SDK、Build Tools、NDK、设备/API/ABI。
3. 先运行原始 fixture 建立基线，再运行保护、未签名验证和外部临时签名后的安装测试。
4. 覆盖正向、错误签名、Payload/Manifest/SO/壳 DEX 篡改、损坏输入和失败原子性。
5. 验证 x86 不会因架构本身被判定为风险。
6. 记录体积、冷启动和内存基线；不得只报告平均值而隐藏高分位退化。

临时签名证书只能由集成测试在忽略目录生成，不得进入产品模块或提交历史。输出交接包，不编辑根 `HandOff.md`。
