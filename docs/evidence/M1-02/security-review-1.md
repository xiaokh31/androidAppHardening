## Findings

### P1: unbounded APK Signing Block materialization

`VerifiedFileDataSource.getByteBuffer` and `copyTo` accepted any `Int` request within the 2 GiB APK limit and allocated a same-sized byte array. Android apksig 9.3.0 requests the complete APK Signing Block as one buffer, so an attacker-controlled near-2-GiB block could terminate the Host with `OutOfMemoryError` instead of a stable `SIGNER_*` failure.

Required closure: parse the block envelope with bounded reads before calling apksig, enforce an explicit Signing Block and contiguous-read limit, fail oversized or truncated declarations as `SIGNER_INVALID`, and add above/below/truncated regression cases.

### P2: public exception cause leaks absolute paths

The public `SignerPolicyException` preserved raw `IOException`, apksig and certificate-parser causes. The top-level message was safe, but an ordinary `printStackTrace` exposed an absolute missing-input path:

```text
PUBLIC=SIGNER_INTERNAL file=secret.apk
Caused by: java.nio.file.NoSuchFileException: C:\tmp\reviewer-secret-parent\secret.apk
```

Required closure: do not attach raw causes to the public exception; test the complete cause chain and rendered stack trace for path and diagnostic leakage.

### P2: magic-only unsigned input is misclassified

An otherwise valid unsigned APK with only the literal `APK Sig Block 42` immediately before the central directory remained unsigned according to official `apksigner`, but the product returned `SIGNER_INVALID`. The implementation checked only the magic and not the head/trailer size envelope.

Required closure: distinguish a complete or plausibly malformed Signing Block envelope from literal ZIP padding. Magic-only input must remain `SIGNER_UNSIGNED`; a structurally residual corrupted block must remain `SIGNER_INVALID`.

### P2: official cross-check and artifact manifest are incomplete

Only `combined.apk` was automatically cross-checked with `apksigner --print-certs`. v1, v2, v3, v4 and rotated fixtures were not individually asserted, rotation output contained multiple platform signer records, and the artifact manifest omitted tampered, malformed, invalid-lineage and `.idsig` artifacts.

Required closure: independently verify all six positive fixtures, record ordinary and rotation certificate digests, record official verification status beside every product negative result, and hash every positive, negative and `.idsig` fixture.
